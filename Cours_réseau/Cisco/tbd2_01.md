# Configurer un SSH sur un équipement

Prérequis : 
- L'équipement doit avoir un nom (`hostname`)
- `enable secret` configuré
- Il faut un nom de domaine (`ip domaine-name nom.du.domaine`)
- Un username/MDP (`username NAME secret PASSWORD`)

##

```
crypto key generate rsa
ip ssh version 2
line vty 0 4
login local
transport input ssh
```
