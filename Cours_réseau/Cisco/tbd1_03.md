# PDU

Le __PDU__ Protocol Data Unit : Données > Segment > Paquet > Trame > Bits  
__Encapuslation__ = couche 7 vers couche 1  

| Couche OSI | Nom                                  | PDU                                      |
| ---------- | ------------------------------------ | ---------------------------------------- |
| 7 à 5      | Application / Présentation / Session | **Données**                              |
| 4          | Transport                            | **Segment** (TCP) / **Datagramme** (UDP) |
| 3          | Réseau                               | **Paquet (Packet)**                      |
| 2          | Liaison de données                   | **Trame (Frame)**                        |
| 1          | Physique                             | **Bits**                                 |
