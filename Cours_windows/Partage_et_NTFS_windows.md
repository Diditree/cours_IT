# Partage de fichiers sur Windows

Droits d'autorisation du partage : Retirer tout le monde et ajouter "Utilisateurs authentifiés" , mettre le maximum de contrôle  

Pourquoi ? Car ce sont les droits NTFS qui vont gérer la sécurité et les accès sur les dossiers

__Partager un fichier dans l'AD depuis le serveur de partage__ : 
- Gestion de l'ordinateur > dossiers partagés > clique droite sur le dossier > lister dans l'ad
